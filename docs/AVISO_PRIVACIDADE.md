# Aviso de privacidade

Este aviso explica, em linguagem simples, o que o Conexão Futuro faz com o que você escreve. Ele vale para estudantes e para as famílias.

## O que é o Conexão Futuro

É um projeto educativo que ajuda estudantes do Ensino Médio a conhecer cursos técnicos do Catálogo Nacional de Cursos Técnicos (CNCT), do MEC. Quem conversa com você é uma **inteligência artificial**, não uma pessoa. As sugestões são só sugestões: quem decide é você.

## A gente não pede dados pessoais

- Não pedimos nome, CPF, idade, gênero, escola, endereço, telefone, e-mail nem redes sociais.
- Se você escrever algum desses dados sem querer, o sistema esconde antes de enviar para a inteligência artificial.
- Não existe cadastro nem login.

## O que fica guardado

- **O texto da conversa não é guardado no servidor.** Ele fica só no seu navegador, e some quando você fecha a aba.
- Se você usar o formulário de apoio, recebe um **código** (ex.: ONDA-4827). Com ele ficam guardados só as suas respostas do formulário, um resumo do seu perfil (como "curte desenhar") e os cursos sugeridos. Nada disso identifica você.
- Para o painel da turma, o professor vê só números da turma inteira (por exemplo, quantas pessoas receberam sugestões de cada área). Ninguém vê as respostas de um estudante.
- Tudo o que é guardado é apagado automaticamente em **60 dias**.

## Quem processa o que você escreve

Para responder, o texto da conversa (já sem dados pessoais) é enviado à **Anthropic**, a empresa que fornece a inteligência artificial. Pelas regras dela, os dados enviados pela API não são usados para treinar os modelos.

## Momentos difíceis

Se você contar que está passando por um momento difícil, a orientação sobre cursos é pausada e você recebe uma mensagem de apoio. Isso não é guardado. Se precisar conversar agora, o **CVV** atende de graça, 24 horas: ligue **188** ou acesse [cvv.org.br](https://cvv.org.br).

## Seus direitos

O projeto segue a Lei Geral de Proteção de Dados (LGPD), com o cuidado especial que ela exige para dados de adolescentes, e o Estatuto da Criança e do Adolescente (ECA). Dúvidas podem ser levadas à coordenação da escola ou ao professor responsável pela oficina.
